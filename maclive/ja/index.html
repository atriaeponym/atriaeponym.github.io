Mac を、スマートフォンでライブ表示

Mac の温度、プロセッサ、メモリ、ディスク、バッテリーを、どこにいてもスマートフォンで確認できます。そのために2 つのソフト（どちらも無料）が必要です：

Mac 側
Computer LiveMac 用 · コンパニオン
計測して送信します。画面はありません。
⇄エンドツーエンド暗号化
スマートフォン側
Mac LiveAndroidComputer LiveiPhone
実際に見るアプリです。

Mac 用 Computer Live はスマートフォンアプリのコンパニオンです。これがないとアプリには何も表示されず、これだけでは Mac 上に何も表示されません。

3 ステップでインストール

1
スマートフォンにアプリをインストール
▶ Android 用 Mac Live（Google Play）iPhone 用 Computer Live（App Store）— 近日公開
2
Mac にコンパニオン Computer Live をインストール

「ダウンロード」フォルダの ComputerLive-1.0.3.dmg をダブルクリックします。

Computer Live を Applications にドラッグ。そのあと開くと、画面上部のメニューバーにアイコンが表示されます。

⬇ コンパニオン Computer Live 1.0.3 をダウンロード
.dmg ファイル · 2.2 MB · 無料 · Apple による公証済み
Apple シリコン搭載 Mac（M1 以降）· macOS 14 以降
3
2 つをつなぐ

Mac の Computer Live メニューで「スマートフォンを追加…」を選び、スマートフォンのアプリで QR コードを読み取ります。これで完了です。

知っておきたいこと

  • アカウント作成不要、広告なし。
  • 計測データはエンドツーエンドで暗号化されて届きます。読めるのはあなたのスマートフォンだけです。
  • Computer Live は自動でアップデートされます。
