Installer en 3 étapes

1
Ouvrez le fichier téléchargé

Double-cliquez sur ComputerLive-1.0.3.dmg dans vos Téléchargements.

2
Glissez Computer Live dans Applications

Puis ouvrez-la : son icône apparaît dans la barre des menus, en haut de l'écran.

3
Scannez le QR code avec votre téléphone

Dans le menu de Computer Live, choisissez « Ajouter un téléphone… » et scannez le code avec l'app Android.
