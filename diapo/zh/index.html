Diapo照片查看器与幻灯片放映，支持 RAW

文件夹 · 磁盘 · RAW · 幻灯片

Diapo 是一款适用于 Windows 和 Android 的照片查看器。它以大图显示一个文件夹或整个硬盘中的所有照片（包括子文件夹），并以自动幻灯片的方式播放。它可以读取相机 RAW 文件（Canon CR2 和 CR3、Nikon NEF、Sony ARW、DNG……），也能打开手机拍摄的 HEIC 照片。只需一个按键或一个手势即可浏览磁盘上的所有照片，而且照片绝不会被修改。

以大图浏览文件夹或磁盘中的所有照片

请选择一个文件夹或整个磁盘：Diapo 还会浏览所有子文件夹。三种模式，任您选择浏览方式：

  • 全屏：只显示照片，周围没有任何内容。
  • 胶片：大图显示照片，并通过缩略图条快速跳转。
  • 印样：缩略图网格，一眼看遍整个文件夹。

照片会根据 EXIF 方向信息以正确方向显示，Diapo 会在每个文件夹中从上次查看的照片继续。

RAW 和 HEIC 查看器

Diapo 无需另装冲印软件，即可读取常见格式和相机 RAW 文件。对于 RAW 文件，它显示相机存储在文件中的预览图：图像立即出现，无需等待冲印处理。

  • RAW：Canon CR2 和 CR3、Nikon NEF、Sony ARW、Fujifilm RAF、Olympus ORF、Panasonic RW2、Pentax PEF、Samsung SRW 和 DNG。
  • Windows 上：JPEG、HEIC、PNG、TIFF、WebP、GIF 和 BMP。
  • Android 上：JPEG、HEIC、PNG、WebP、GIF、BMP 和 AVIF。

自动照片幻灯片放映

点按幻灯片放映按钮，即可从主屏幕或当前照片开始自动播放照片。单击或轻点一次即可暂停：上一张、继续、下一张或停止。在 PC 上，空格键可开始和停止幻灯片放映。

适用于 Windows PC 和 Android

核心功能处处相同：三种模式、RAW 格式、个人收藏、精选、照片绝不修改。每个版本都针对其设备进行了适配。

Windows PC

  • 打开一个文件夹或整个磁盘；也可以将文件夹拖入窗口。
  • 使用方向键 ← →、单击、鼠标滚轮或触控板前进；按 Esc 返回。
  • 按 F 键可将照片加入个人收藏。
  • Windows 10（版本 1809）或更高版本，通过 Microsoft Store 获取。

Android

  • 手机中的所有照片，按文件夹分类，或您选择的文件夹。
  • 滑动切换照片，双指缩放，轻点两下进入全屏。
  • Android 8 或更高版本，通过 Google Play 获取。

常见问题

Diapo 可以读取哪些 RAW 格式？

Canon CR2 和 CR3、Nikon NEF、Sony ARW、Fujifilm RAF、Olympus ORF、Panasonic RW2、Pentax PEF、Samsung SRW 和 DNG，Windows 和 Android 均支持。Diapo 显示相机存储在文件中的预览图，不会冲印或修改 RAW 文件。

能在 Windows PC 上打开 iPhone 的 HEIC 照片吗？

可以。Diapo 使用自带的解码器读取 HEIC 和 HEIF 照片：只需打开存放这些照片的文件夹或磁盘即可。

Diapo 会修改我的照片吗？

不会。Diapo 绝不修改、移动、重命名或删除任何照片。只有在您复制精选时，它才会在您选择的文件夹中创建副本。

如何开始幻灯片放映？

在主屏幕或照片上轻点或单击幻灯片放映按钮。在 PC 上，也可以按空格键开始。单击或轻点一次即可暂停。

Diapo 的价格是多少？

在 Windows 上，Microsoft Store 售价 2.99 €，可试用 15 天。在 Android 上，安装无需付费，试用 14 天后，通过应用内一次性购买（2.99 €）即可继续使用。没有订阅。

Diapo 支持哪些设备？

支持 Windows 10（版本 1809）或更高版本的 PC（通过 Microsoft Store），以及 Android 8 或更高版本（通过 Google Play）。iPhone 和 Mac 版本尚未登陆 App Store。

我的照片会被发送到互联网吗？

不会。Diapo 在您的设备上读取照片，不发送任何内容：无需账户，无广告，无统计分析。详情请参阅隐私政策。
