Diapo画像ビューアとスライドショー、RAW にも対応

フォルダ · ディスク · RAW · スライドショー

Diapo は Windows と Android 向けの画像ビューアです。フォルダやハードディスク全体の写真を、サブフォルダも含めてすべて大きく表示し、自動のスライドショーで再生します。カメラの RAW ファイル（Canon CR2・CR3、Nikon NEF、Sony ARW、DNG など）を読み込み、スマートフォンの HEIC 写真も開けます。キーひとつ、操作ひとつでディスク内のすべての写真を見られ、写真が変更されることはありません。

フォルダやディスクのすべての写真を大きく表示

フォルダ、またはディスク全体を選んでください。Diapo はすべてのサブフォルダも読み込みます。お好みに合わせて選べる 3 つのモード：

  • フルスクリーン：写真だけを、周りに何も置かずに表示します。
  • フィルム：写真を大きく表示し、サムネイルの帯で先の写真へすばやく移動できます。
  • ベタ焼き：サムネイルの一覧で、フォルダ全体をひと目で確認できます。

写真は EXIF の向き情報に従って正しい向きで表示され、Diapo はフォルダごとに最後に見た写真から再開します。

RAW と HEIC に対応したビューア

Diapo は一般的な形式とカメラの RAW ファイルを、現像ソフトなしで読み込みます。RAW の場合は、カメラがファイルに保存したプレビュー画像を表示するため、現像を待たずにすぐに画像が表示されます。

  • RAW：Canon CR2・CR3、Nikon NEF、Sony ARW、Fujifilm RAF、Olympus ORF、Panasonic RW2、Pentax PEF、Samsung SRW、DNG。
  • Windows：JPEG、HEIC、PNG、TIFF、WebP、GIF、BMP。
  • Android：JPEG、HEIC、PNG、WebP、GIF、BMP、AVIF。

自動のフォトスライドショー

スライドショーボタンを押すと、ホーム画面や表示中の写真から、写真が自動で切り替わります。クリックまたはタップで一時停止し、前の写真、再開、次の写真、終了を選べます。PC ではスペースキーでスライドショーを開始・停止できます。

Windows PC と Android に対応

基本はどこでも同じです：3 つのモード、RAW 形式、お気に入り、セレクション、写真は一切変更しません。各バージョンはそれぞれの端末に合わせて作られています。

Windows PC

  • フォルダまたはディスク全体を開けます。フォルダをウィンドウにドラッグすることもできます。
  • 矢印キー ← →、クリック、マウスホイール、タッチパッドで次へ進み、Esc キーで戻ります。
  • F キーで写真をお気に入りに追加できます。
  • Windows 10（バージョン 1809）以降、Microsoft Store から入手できます。

Android

  • スマートフォン内のすべての写真をフォルダ別に、または選んだフォルダを表示します。
  • スワイプで写真を切り替え、ピンチでズーム、ダブルタップでフルスクリーンになります。
  • Android 8 以降、Google Play から入手できます。

iPhone 版と Mac 版は、後日 App Store で公開予定です。

お気に入りと共有用のセレクション

ハートのマークで写真をお気に入りに追加できます。複数の写真を共有するにはセレクションを開き、フォルダを見ながらクリックまたはタップで写真に印を付けて、フォルダにコピーします。重複した写真はファイル名が違っても内容で判定して除外されます。

写真はそのまま、お使いの端末の中に

  • Diapo が写真を変更、移動、名前変更、削除することはありません。作成するのは、ご指示があったときのコピーだけです。
  • サムネイルは表示中のみメモリに保持され、ディスクにキャッシュは書き込まれません。
  • アカウント、広告、アクセス解析ツールは一切なく、写真がインターネットに送信されることもありません。

詳しくはプライバシーポリシー（英語）をご覧ください。

よくある質問

Diapo はどの RAW 形式を読み込めますか？

Canon CR2・CR3、Nikon NEF、Sony ARW、Fujifilm RAF、Olympus ORF、Panasonic RW2、Pentax PEF、Samsung SRW、DNG に、Windows でも Android でも対応しています。Diapo はカメラがファイルに保存したプレビュー画像を表示し、RAW を現像したり変更したりはしません。

iPhone の HEIC 写真を Windows PC で開けますか？

はい。Diapo は独自のデコーダーで HEIC・HEIF 写真を読み込みます。写真の入ったフォルダかディスクを開くだけです。

Diapo は写真を変更しますか？

いいえ。Diapo が写真を変更、移動、名前変更、削除することはありません。セレクションをコピーするときに、選んだフォルダへコピーを作成するだけです。

スライドショーはどうやって始めますか？

ホーム画面または写真から、スライドショーボタンをタップまたはクリックしてください。PC ではスペースキーでも開始できます。クリックまたはタップで一時停止します。

Diapo の価格はいくらですか？

Windows では Microsoft Store で 2.99 €、15 日間の試用期間付きです。Android ではインストールに費用はかからず、14 日間のお試し期間のあと、アプリ内の買い切り購入（2.99 €）で引き続きご利用いただけます。サブスクリプションはありません。

Diapo はどの端末で使えますか？

Windows 10（バージョン 1809）以降の PC では Microsoft Store から、Android 8 以降では Google Play から入手できます。iPhone 版と Mac 版はまだ App Store にはありません。

写真がインターネットに送信されることはありますか？

いいえ。Diapo はお使いの端末上で写真を読み込み、何も送信しません。アカウント、広告、アクセス解析は一切ありません。詳しくはプライバシーポリシーをご覧ください。
