常见问题

如何在 Windows 上按拍摄日期整理照片？

将您的硬盘和文件夹添加到 Photothèque：它会读取每张照片的拍摄日期，并将副本按年和月归档。没有日期的照片放入单独的文件夹，月份绝不凭空推测。

Photothèque 如何识别重复照片？

根据内容：当两个文件的 SHA-256 哈希值相同时才视为重复，而不是因为名称相同。两个不同的 IMG_0001.jpg 都会保留。

我的原始照片会被修改或删除吗？

不会。Photothèque 绝不会修改、移动、重命名或删除来源中的任何文件：它将文件复制到新的照片库中，然后重新读取每个副本。

几乎相同的照片会怎样处理？

重新导出、重新压缩或调整过尺寸的照片会并排显示给您，由您来选择。未经您同意，不会舍弃任何照片。

Photothèque 多少钱？

安装免费，读取硬盘和查看汇总也免费。经过校验的复制、几乎相同照片的处理、证书和备份副本需要订阅：每月 2.99 € 或每年 24.99 €，无需长期承诺，可随时在您的 Microsoft 账户中取消。

我的照片会被发送到互联网吗？

不会。一切都在您的电脑上完成：无需账户，没有服务器，不发送任何照片。详情请参阅隐私政策。

通过 Microsoft Store，在装有 Windows 10（1809 版）或更高版本的电脑上运行。
