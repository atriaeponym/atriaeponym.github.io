English

Photothèqueจัดเรียงรูปภาพตามวันที่ ไม่มีรูปซ้ำ

ไดรฟ์ · รูปซ้ำ · เรียงตามวันที่ · หลักฐาน

Photothèque เป็นโปรแกรมจัดระเบียบรูปภาพสำหรับ Windows รูปภาพของคุณกระจัดกระจายอยู่ในพีซีเครื่องเก่า ฮาร์ดดิสก์ภายนอก แฟลชไดรฟ์ USB หรือข้อมูลสำรองจากโทรศัพท์หรือไม่? Photothèque รวบรวมรูปภาพจากหลายไดรฟ์และโฟลเดอร์ ตรวจหารูปซ้ำจากเนื้อหาของไฟล์ แล้วสร้างคลังรูปภาพที่ครบถ้วนเพียงคลังเดียว เรียงตามวันที่ถ่าย และพิสูจน์ให้คุณเห็นว่าไม่มีรูปใดสูญหายระหว่างทาง ไฟล์ต้นฉบับของคุณจะไม่ถูกแก้ไขเลย

ไม่มีโฆษณา · ไม่ต้องมีบัญชี · ไม่มีการส่งข้อมูลใด ๆ

ดาวน์โหลดได้ที่Microsoft Storeพีซี Windows 10 (1809) ขึ้นไป

รวมรูปภาพทั้งหมดจากหลายไดรฟ์

เพิ่มไดรฟ์และโฟลเดอร์ได้มากเท่าที่ต้องการ โปรแกรมจะอ่านเท่านั้น ไม่แก้ไข หากถอดไดรฟ์ออกระหว่างทาง การอ่านจะดำเนินต่อจากจุดที่หยุดไว้

จากนั้นจะแสดงสรุปผลให้ฟรี: มีรูปภาพและวิดีโอกี่รายการ สำเนาที่เหมือนกันทุกประการเกินมากี่รายการ กี่รายการที่มีอยู่ในไดรฟ์เดียวเท่านั้น (ควรเก็บรักษาก่อน) และกี่รายการที่ไม่มีวันที่

ตรวจหารูปซ้ำจากเนื้อหา

  • รูปซ้ำทุกประการ: เนื้อหาเหมือนกัน ตรวจสอบด้วยค่าแฮช SHA-256 ไม่ใช่เพราะชื่อเหมือนกัน ไฟล์ IMG_0001.jpg สองไฟล์ที่ต่างกันจะถูกเก็บไว้ทั้งคู่
  • รูปภาพที่เกือบเหมือนกัน (ส่งออกใหม่ บีบอัดใหม่ หรือปรับขนาด): จะแสดงให้คุณดูเทียบกัน และคุณเป็นผู้เลือก ไม่มีสิ่งใดถูกคัดออกโดยไม่ได้รับความเห็นชอบจากคุณ

คลังรูปภาพที่เรียงตามวันที่ถ่าย

รูปภาพและวิดีโอแต่ละรายการจะถูกคัดลอกเพียงครั้งเดียว และจัดเก็บตามปีและเดือนจากวันที่ถ่าย โปรแกรมไม่เดาเดือนเอง รูปที่ไม่มีวันที่จะอยู่ในโฟลเดอร์แยกต่างหาก ชื่อโฟลเดอร์เดิมของคุณจะกลับมาในรูปแบบอัลบั้ม โดยไม่ใช้พื้นที่เพิ่ม

หลักฐานว่าไม่มีรูปใดสูญหาย

  • การคัดลอกที่ผ่านการตรวจสอบ: ทุกไฟล์ที่คัดลอกจะถูกอ่านซ้ำและตรวจสอบด้วยค่าแฮช SHA-256
  • ใบรับรองความครบถ้วน (PDF): อธิบายทุกไฟล์จากทุกแหล่งข้อมูล ว่าอยู่ในคลังรูปภาพ หรือถูกคัดออกตามที่คุณเลือก
  • สำเนาสำรองบนไดรฟ์อื่น ตรวจสอบด้วยวิธีเดียวกัน

รูปแบบไฟล์

JPEG, HEIC, PNG, TIFF, WebP, GIF, BMP, AVIF, RAW (Canon CR2/CR3, Nikon NEF, Sony ARW, Fujifilm RAF, Olympus ORF, Panasonic RW2, DNG…) และวิดีโอ (MOV, MP4, AVI, MTS, MKV…)

รูปภาพของคุณยังคงเหมือนเดิม และอยู่กับคุณ

  • Photothèque ไม่แก้ไข ไม่ย้าย ไม่เปลี่ยนชื่อ และไม่ลบไฟล์ใดในแหล่งข้อมูลของคุณ โปรแกรมเพียงคัดลอกไปยังคลังรูปภาพใหม่
  • ทุกอย่างทำงานบนพีซีของคุณ: ไม่ต้องมีบัญชี ไม่มีเซิร์ฟเวอร์ ไม่มีการส่งรูปภาพใด ๆ

รายละเอียดอยู่ในนโยบายความเป็นส่วนตัว

ราคา: อ่านฟรี คัดลอกด้วยการสมัครสมาชิก

  • ฟรี: การติดตั้ง การอ่านไดรฟ์ของคุณ และสรุปผล
  • การสมัครสมาชิก: 2.99 € ต่อเดือน หรือ 24.99 € ต่อปี สำหรับการคัดลอกที่ผ่านการตรวจสอบ รูปภาพที่เกือบเหมือนกัน ใบรับรอง และสำเนาสำรอง
  • ไม่มีข้อผูกมัด ยกเลิกได้ทุกเมื่อในบัญชี Microsoft ของคุณ การชำระเงินผ่าน Microsoft Store: Atria.Eponym ไม่ได้รับข้อมูลบัตรหรือชื่อของคุณ

คำถามที่พบบ่อย

จะจัดเรียงรูปภาพตามวันที่ถ่ายบน Windows ได้อย่างไร?

เพิ่มไดรฟ์และโฟลเดอร์ของคุณใน Photothèque โปรแกรมจะอ่านวันที่ถ่ายของรูปภาพแต่ละรูป และจัดเก็บสำเนาตามปีและเดือน รูปที่ไม่มีวันที่จะอยู่ในโฟลเดอร์แยกต่างหาก โปรแกรมไม่เดาเดือนเอง

Photothèque ตรวจหารูปซ้ำอย่างไร?

จากเนื้อหา: ไฟล์สองไฟล์จะถือว่าซ้ำกันเมื่อค่าแฮช SHA-256 ตรงกัน ไม่ใช่เพราะมีชื่อเหมือนกัน ไฟล์ IMG_0001.jpg สองไฟล์ที่ต่างกันจะถูกเก็บไว้ทั้งคู่

รูปภาพต้นฉบับของฉันจะถูกแก้ไขหรือลบหรือไม่?

ไม่ Photothèque ไม่แก้ไข ไม่ย้าย ไม่เปลี่ยนชื่อ และไม่ลบไฟล์ใดในแหล่งข้อมูลของคุณ โปรแกรมคัดลอกไฟล์ไปยังคลังรูปภาพใหม่ แล้วอ่านสำเนาแต่ละไฟล์ซ้ำ

รูปภาพที่เกือบเหมือนกันจะเป็นอย่างไร?

รูปภาพที่ส่งออกใหม่ บีบอัดใหม่ หรือปรับขนาด จะแสดงให้คุณดูเทียบกัน และคุณเป็นผู้เลือก ไม่มีสิ่งใดถูกคัดออกโดยไม่ได้รับความเห็นชอบจากคุณ

Photothèque ราคาเท่าไร?

การติดตั้งฟรี และการอ่านไดรฟ์กับการดูสรุปผลก็ฟรีเช่นกัน การคัดลอกที่ผ่านการตรวจสอบ รูปภาพที่เกือบเหมือนกัน ใบรับรอง และสำเนาสำรอง ต้องสมัครสมาชิก: 2.99 € ต่อเดือน หรือ 24.99 € ต่อปี ไม่มีข้อผูกมัด ยกเลิกได้ทุกเมื่อในบัญชี Microsoft ของคุณ

รูปภาพของฉันจะถูกส่งขึ้นอินเทอร์เน็ตหรือไม่?

ไม่ ทุกอย่างทำงานบนพีซีของคุณ: ไม่ต้องมีบัญชี ไม่มีเซิร์ฟเวอร์ ไม่มีการส่งรูปภาพใด ๆ รายละเอียดอยู่ในนโยบายความเป็นส่วนตัว

Photothèque ใช้งานได้บนอุปกรณ์ใดบ้าง?

บนพีซีที่ใช้ Windows 10 (เวอร์ชัน 1809) ขึ้นไป ผ่าน Microsoft Store
