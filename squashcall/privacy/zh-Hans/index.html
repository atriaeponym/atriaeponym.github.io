隐私政策 — Squash Call

最后更新：2026年11月21日

要点：您无需账户即可使用 Squash Call。没有广告，没有受众统计，没有跟踪，也不出售数据。离开您手机的数据仅用于让应用正常运行，所有内容均在下文说明。

数据去向

存放于 Supabase 位于巴黎（欧盟）的数据中心。通知通过 Firebase Cloud Messaging（Google）发送，登录邮件通过 Resend 发送。

无账户时

  • 通知：手机的通知标识符（不含姓名或电子邮件）、语言、您的通知设置以及您关注的比赛。一旦 Firebase 判定其无效（例如卸载应用后），该标识符即被删除。
  • 全屏公告：安装时随机生成的一个编号，用于确保每条公告只显示一次。
  • 您收藏的球员以及您在“您的判罚”中的选择仅保存在手机上。

有账户时（可选）

账户会保存您的预测、您在“您的判罚”中的选择以及您的个人资料。账户通过您的电子邮件地址创建，无需密码：您会收到一个链接。服务器保存：

  • 您的电子邮件地址，其他人永远看不到；
  • 您的个人资料：昵称、头像（一幅绘制的图像，或您图库中的一张照片，先在手机上缩小再上传到服务器）、一种随机选定的颜色、您的动画设置；
  • 您的预测（胜者和比分），以及服务器计算但不在任何地方显示的总积分；
  • 您在“您的判罚”中的选择（No let、Let 或 Stroke），以及裁判的判罚、当时的局数和比分。

登录后，手机会与您的账户关联；一旦退出登录，关联即解除。

其他人能看到什么

  • 已登录的用户可以读取您的个人资料：昵称、头像、颜色、动画和通知设置、总积分。应用只显示其中的昵称和头像。您的头像照片保存在一个公开的网址上。
  • 您的预测和您在“您的判罚”中的选择仅向您本人显示。比赛结束后，其他人只能看到每个选项的球迷人数。

球迷动画

当您点按庆祝按钮时，手机会实时向所有已连接的手机发送：动画类型、比赛、您的昵称（无账户时为“Fan”）、您的绘制头像和您的颜色。这些动画不会被保存。

崩溃报告

应用因错误关闭后，会在下次启动时发送：应用版本、手机型号、Android 版本以及错误的技术记录。不含账户和电子邮件：该报告仅用于修复错误。

来源、图片和链接

比赛结果、对阵表、赛程和排名来自壁球的公开网站，经由 Squash Call 的服务器获取。球员肖像直接从这些网站的服务器加载，城市照片来自 Wikimedia Commons：与访问任何网页一样，这些网站会看到您手机的 IP 地址。壁球规则的链接会在您的浏览器中打开。

您手机上的数据

您的账户会话、最新数据和图片的副本、您收藏的球员、您在“您的判罚”中的选择，以及登录前做出的一项预测。这些数据不包含在 Android 备份中，卸载应用后即会消失。

删除您的数据

设置（右上角您的头像）› 账户 ›“删除我的账户”会立即并永久删除您的账户、电子邮件地址、个人资料及其照片、您的预测以及您在“您的判罚”中的选择。已关注的比赛仍保留在手机上，但与您不再有任何关联。没有账户时，卸载应用即可。

应用不会做的事

没有广告，没有受众统计，没有跟踪，也不会出售或出于商业目的共享您的数据。应用不会请求您的位置、通讯录或文件访问权限：照片通过 Android 的选择器提供，应用只能获得您所选的那张图片。
