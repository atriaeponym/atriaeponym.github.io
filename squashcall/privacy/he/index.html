מדיניות פרטיות — Squash Call

עדכון אחרון: 21 בנובמבר 2026

העיקר: ניתן להשתמש ב־Squash Call ללא חשבון. ללא פרסומות, ללא מדידת קהל, ללא מעקב, ללא מכירת נתונים. מה שיוצא מהטלפון שלכם משמש אך ורק להפעלת האפליקציה, והכול מתואר להלן.

לאן הנתונים הולכים

אל Supabase, במרכז נתונים בפריז (האיחוד האירופי). ההתראות עוברות דרך Firebase Cloud Messaging (Google), והודעות הדוא״ל להתחברות דרך Resend.

ללא חשבון

  • התראות: מזהה ההתראות של הטלפון (ללא שם וללא דוא״ל), השפה, הגדרות ההתראות שלכם והמשחקים שאתם עוקבים אחריהם. המזהה נמחק ברגע ש־Firebase מכריז שהוא אינו תקף, למשל לאחר הסרת האפליקציה.
  • הודעות במסך מלא: מספר שנבחר באקראי בעת ההתקנה, כדי שכל הודעה תוצג פעם אחת בלבד.
  • השחקנים המועדפים שלכם והבחירות שלכם ב“ההחלטה שלכם” נשארים בטלפון.

עם חשבון (רשות)

החשבון שומר את התחזיות שלכם, את הבחירות שלכם ב“ההחלטה שלכם” ואת הפרופיל שלכם. הוא נוצר באמצעות כתובת הדוא״ל שלכם, ללא סיסמה: אתם מקבלים קישור. השרת שומר:

  • את כתובת הדוא״ל שלכם, שלעולם אינה גלויה לאחרים;
  • את הפרופיל שלכם: כינוי, אווטאר (ציור, או תמונה מהגלריה שלכם, שמוקטנת בטלפון ואז מועלית לשרת), צבע שנבחר באקראי, ובחירת האנימציות שלכם;
  • את התחזיות שלכם (מנצח ותוצאה), וסך נקודות שהשרת מחשב אך אינו מציג בשום מקום;
  • את הבחירות שלכם ב“ההחלטה שלכם” (No let, Let או Stroke), יחד עם החלטת השופט, המשחקון והתוצאה באותו רגע.

כשאתם מחוברים, הטלפון מקושר לחשבון שלכם; הקישור מתבטל ברגע שאתם מתנתקים.

מה אחרים רואים

  • משתמשים מחוברים יכולים לקרוא את הפרופיל שלכם: כינוי, אווטאר, צבע, הגדרות אנימציות והתראות, סך נקודות. האפליקציה מציגה מתוכם רק את הכינוי והאווטאר. תמונת הפרופיל שלכם נשמרת בכתובת אינטרנט ציבורית.
  • התחזיות שלכם והבחירות שלכם ב“ההחלטה שלכם” מוצגות רק לכם. לאחר סיום המשחק, אחרים רואים רק את מספר האוהדים שבחרו בכל אפשרות.

אנימציות האוהדים

כשאתם נוגעים בכפתור חגיגה, הטלפון שולח בזמן אמת לכל הטלפונים המחוברים: את סוג האנימציה, המשחק, הכינוי שלכם (“Fan” ללא חשבון), האווטאר המצויר שלכם והצבע שלכם. אנימציות אלה אינן נשמרות.

דוחות קריסה

לאחר סגירה עקב שגיאה, האפליקציה שולחת בהפעלה הבאה: את הגרסה שלה, דגם הטלפון, גרסת Android והעקבה הטכנית של השגיאה. ללא חשבון וללא דוא״ל: הדוח משמש אך ורק לתיקון השגיאה.

מקורות, תמונות וקישורים

תוצאות, טבלאות, לוחות זמנים ודירוגים מגיעים מאתרי הסקווש הציבוריים, דרך השרת של Squash Call. תמונות השחקנים מגיעות ישירות מהשרתים של אתרים אלה, ותמונות הערים מ־Wikimedia Commons: אתרים אלה רואים את כתובת ה־IP של הטלפון שלכם, כמו בכל דף אינטרנט. הקישורים לחוקי הסקווש נפתחים בדפדפן שלכם.

בטלפון שלכם

ההתחברות לחשבון שלכם, עותק של הנתונים והתמונות האחרונים, השחקנים המועדפים שלכם, הבחירות שלכם ב“ההחלטה שלכם” ותחזית שנעשתה לפני ההתחברות. נתונים אלה אינם נכללים בגיבוי של Android ונעלמים עם הסרת האפליקציה.

מחיקת הנתונים שלכם

הגדרות (האווטאר שלכם, למעלה משמאל) › חשבון › “מחיקת החשבון שלי” מוחק מיד ולצמיתות את החשבון שלכם, את כתובת הדוא״ל שלכם, את הפרופיל ואת התמונה שלו, את התחזיות שלכם ואת הבחירות שלכם ב“ההחלטה שלכם”. המשחקים שבמעקב נשארים בטלפון, ללא כל קשר אליכם. ללא חשבון, די בהסרת האפליקציה.

מה האפליקציה אינה עושה

ללא פרסום, ללא מדידת קהל, ללא מעקב, ללא מכירה או שיתוף מסחרי של הנתונים שלכם. היא אינה מבקשת את המיקום שלכם, את אנשי הקשר שלכם או גישה לקבצים שלכם: תמונה נבחרת דרך בורר התמונות של Android, שמעביר לה רק את התמונה שנבחרה.

הזכויות שלכם

גישה לנתונים שלכם, תיקונם או מחיקתם בכל עת, בכתיבה לכתובת שלהלן. ניתן גם לפנות אל CNIL (cnil.fr).
