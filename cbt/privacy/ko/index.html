개인정보 처리방침 — 보이스피싱 방패

최종 업데이트: 2026년 10월 29일

보이스피싱 방패는 프랑스에 기반을 둔 개인 개발자 Atria.Eponym에서 배포합니다. 문의: atria.eponym@gmail.com

요약: 앱은 고객님의 전화번호도, 통화도, 연락처도 알지 못합니다. 서버는 익명 ID만 볼 수 있습니다.

휴대폰에만 남고 다른 곳에는 저장되지 않는 정보

  • 가족에게 보이는 본인의 이름과 사진, 가족의 이름과 사진, 확인 기록
  • 키: 휴대폰의 보안 칩 안에서 생성되며 절대 밖으로 나가지 않습니다.

중계 서버(Cloudflare 호스팅)가 보는 정보

  • 휴대폰마다 해당 휴대폰의 공개 키에서 만든 익명 ID 하나와 그 공개 키
  • 해당 휴대폰으로 알림을 보내는 데 쓰는 토큰과 마지막 접속 시각
  • 누가 누구와 연결되어 있는지(익명 ID 형태)
  • 진행 중인 질문과 서명된 답변: 만료 1시간 후 삭제됩니다(질문은 2분 후 만료됩니다)
  • 연결 과정에서 주고받는 프로필: 초대 링크에만 들어 있는 비밀 키로 암호화되어 서버는 읽을 수 없습니다. 늦어도 24시간 후 삭제됩니다.

앱이 절대 하지 않는 일

앱은 통화나 메시지를 읽거나, 주소록에 접근하거나, 위치를 추적하거나, 광고를 표시하거나, 이용 현황을 측정하거나, 데이터를 판매하거나 공유하는 일을 절대 하지 않습니다.

알림

질문은 Android에서는 Google(Firebase Cloud Messaging), iPhone에서는 Apple(Apple Push Notification service)을 통해 전달됩니다. 알림에는 익명 ID와 서명만 들어 있고, 이름이나 문장은 절대 들어 있지 않습니다. 문장은 고객님의 휴대폰이 직접 만듭니다.

데이터 삭제

가족을 삭제하면 양쪽의 연결이 즉시 끊어집니다. 설정의 ‘새 휴대폰’을 사용하면 모든 연결이 삭제됩니다. 앱을 삭제하면 앱이 휴대폰에 보관하던 모든 정보가 지워집니다. 서버에 남은 익명 ID로는 고객님을 식별할 수 없습니다. 모든 요청은 다음 주소로 보내 주세요: atria.eponym@gmail.com

앱은 어떤 개인 정보도 요구하지 않습니다. 자녀는 부모가 연결할 수 있습니다.
