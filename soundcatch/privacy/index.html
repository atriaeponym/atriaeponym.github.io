Politique de confidentialité — SoundCatch

Dernière mise à jour : 23 octobre 2026 · English

SoundCatch (anciennement « MP3 Universal Converter » sur Mac) est un enregistreur audio pour Mac, Windows, iPhone et Android. Il enregistre le son d'une application, ou ouvre un fichier audio ou vidéo, vous permet d'en couper des passages, puis exporte un fichier là où vous le décidez. Cette page décrit chaque version.

L'essentiel : aucune donnée collectée, aucun compte, aucune publicité, aucun outil de mesure d'audience. L'application ne se connecte à aucun serveur : le son que vous enregistrez, les fichiers que vous ouvrez et ceux que vous exportez restent sur votre appareil.

Qui est responsable du traitement

SoundCatch est éditée par Atria.Eponym, développeur individuel établi en France. Contact : atria.eponym@gmail.com

Sur Mac

  • Enregistrement audio : macOS vous demande une fois l'autorisation « Enregistrement audio ». L'application ne capte que le son de l'application que vous avez choisie, et seulement entre le moment où vous cliquez sur le bouton d'enregistrement et celui où vous l'arrêtez. Elle n'utilise pas le micro.
  • Fichiers : elle lit uniquement les fichiers que vous ouvrez ou déposez dans sa fenêtre, et écrit uniquement le fichier exporté, dans le dossier que vous avez choisi. Les copies de travail sont rangées dans le dossier temporaire de macOS et effacées à la fermeture.
  • Liste des applications : pour vous proposer les applications qui jouent du son, elle consulte la liste que macOS tient des applications audio ouvertes. Cette liste n'est ni enregistrée ni transmise.
  • Préférences : le dernier format, la dernière source, le volume d'écoute et le dossier d'export sont mémorisés sur votre Mac, dans les préférences de l'application. La version du Mac App Store y ajoute le nombre d'exports réussis et la date de la dernière demande d'avis.
  • Demande d'avis (version Mac App Store) : après le deuxième export réussi, au plus une fois tous les 120 jours, l'application demande à macOS d'afficher la fenêtre d'avis officielle de l'App Store. Cette fenêtre est gérée par Apple ; l'application ne sait pas si vous avez laissé une note.

Sur Windows

  • Le son d'une application : SoundCatch ne capte que le son de l'application que vous avez choisie (ou tout le son du PC si vous le choisissez), et seulement entre le moment où vous cliquez sur le bouton d'enregistrement et celui où vous l'arrêtez. Elle n'utilise pas le micro.
  • Fichiers : elle lit uniquement les fichiers que vous ouvrez ou déposez dans sa fenêtre, et écrit uniquement le fichier exporté, dans le dossier que vous avez choisi. Les copies de travail sont rangées dans le dossier temporaire de Windows et effacées à la fermeture.
  • Préférences et demande d'avis : comme sur Mac, les préférences restent sur votre PC ; la version du Microsoft Store demande à Windows d'afficher la fenêtre d'avis officielle après le deuxième export réussi, au plus une fois tous les 120 jours.
  • Aucune donnée collectée, aucun compte, aucune publicité, aucune connexion à un serveur.

Sur iPhone

  • Le son d'une autre appli : quand vous lancez la diffusion depuis SoundCatch, iOS transmet à l'extension de SoundCatch le son joué par les applis. Elle ne garde que ce son ; l'image de l'écran et le micro sont écartés dès leur arrivée. Le son est rangé dans l'espace de SoundCatch sur votre iPhone, jusqu'à ce que vous le supprimiez.
  • Le micro : utilisé seulement quand vous touchez « Enregistrer avec le micro », après l'autorisation demandée par iOS.
  • Fichiers et vidéos : SoundCatch lit uniquement le fichier ou la vidéo que vous choisissez (sélecteurs d'iOS, sans accès à toute la photothèque). Le fichier exporté va où vous le décidez (Fichiers ou partage) ; l'appli n'en garde pas de copie.
  • Aucune donnée collectée, aucun compte, aucune publicité, aucune connexion à un serveur.

Sur Android

  • Le son des autres applis : quand vous lancez l'enregistrement, Android vous demande l'autorisation de capture ; il exige pour cela l'autorisation « Micro », mais SoundCatch n'enregistre que le son joué par les applis (musique, vidéos, jeux), jamais le micro. Une notification reste affichée tant que l'enregistrement dure.
  • Fichiers : SoundCatch lit uniquement le fichier que vous choisissez avec le sélecteur d'Android et écrit le fichier exporté à l'endroit que vous choisissez. Les enregistrements et les copies de travail restent dans l'espace privé de l'application sur votre téléphone.
  • Aucune donnée collectée, aucun compte, aucune publicité, aucune connexion à un serveur.

Ce que l'application n'envoie pas

Rien. Elle ne contient aucun outil de statistiques, de publicité ou de rapport de plantage, et n'échange aucune donnée avec l'éditeur ni avec un tiers.
