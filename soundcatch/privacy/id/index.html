Kebijakan privasi — SoundCatch

Terakhir diperbarui: 23 Oktober 2026

SoundCatch (sebelumnya “MP3 Universal Converter” di Mac) adalah perekam audio untuk Mac, Windows, iPhone, dan Android. Aplikasi ini merekam suara sebuah aplikasi, atau membuka file audio atau video, memungkinkan Anda memotong bagian-bagiannya, lalu mengekspor file ke tempat yang Anda tentukan. Halaman ini menjelaskan setiap versi.

Intinya: tidak ada data yang dikumpulkan, tanpa akun, tanpa iklan, tanpa analitik. Aplikasi ini tidak terhubung ke server mana pun: suara yang Anda rekam, file yang Anda buka, dan file yang Anda ekspor tetap berada di perangkat Anda.

Siapa yang bertanggung jawab

Di Mac

  • Perekaman audio: macOS meminta izin “Rekaman Audio” kepada Anda satu kali. Aplikasi hanya merekam suara dari aplikasi yang Anda pilih, dan hanya sejak Anda mengklik tombol rekam hingga Anda menghentikannya. Aplikasi ini tidak menggunakan mikrofon.
  • File: aplikasi hanya membaca file yang Anda buka atau letakkan di jendelanya, dan hanya menulis file hasil ekspor, di folder yang Anda pilih. Salinan kerja disimpan di folder sementara macOS dan dihapus saat aplikasi ditutup.
  • Daftar aplikasi: untuk menawarkan aplikasi yang memutar suara, aplikasi membaca daftar aplikasi audio yang terbuka yang dicatat oleh macOS. Daftar ini tidak disimpan dan tidak dikirim.
  • Preferensi: format, sumber, volume dengar, dan folder ekspor terakhir disimpan di Mac Anda, dalam preferensi aplikasi. Versi Mac App Store juga menyimpan jumlah ekspor yang berhasil dan tanggal permintaan ulasan terakhir.
  • Permintaan ulasan (versi Mac App Store): setelah ekspor kedua yang berhasil, paling banyak satu kali setiap 120 hari, aplikasi meminta macOS menampilkan jendela ulasan resmi App Store. Jendela tersebut dikelola oleh Apple; aplikasi tidak mengetahui apakah Anda memberikan rating.

Di Windows

  • Suara sebuah aplikasi: SoundCatch hanya merekam suara dari aplikasi yang Anda pilih (atau seluruh suara PC jika Anda memilihnya), dan hanya sejak Anda mengklik tombol rekam hingga Anda menghentikannya. Aplikasi ini tidak menggunakan mikrofon.
  • File: aplikasi hanya membaca file yang Anda buka atau letakkan di jendelanya, dan hanya menulis file hasil ekspor, di folder yang Anda pilih. Salinan kerja disimpan di folder sementara Windows dan dihapus saat aplikasi ditutup.
  • Preferensi dan permintaan rating: seperti di Mac, preferensi tetap berada di PC Anda; versi Microsoft Store meminta Windows menampilkan jendela rating resmi setelah ekspor kedua yang berhasil, paling banyak satu kali setiap 120 hari.
  • Tidak ada data yang dikumpulkan, tanpa akun, tanpa iklan, tanpa koneksi ke server mana pun.

Di iPhone

  • Suara aplikasi lain: saat Anda memulai siaran dari SoundCatch, iOS meneruskan suara yang diputar oleh aplikasi ke ekstensi SoundCatch. Ekstensi ini hanya menyimpan suara tersebut; gambar layar dan mikrofon dibuang begitu diterima. Suara disimpan di ruang SoundCatch di iPhone Anda hingga Anda menghapusnya.
  • Mikrofon: hanya digunakan saat Anda mengetuk « Enregistrer avec le micro », setelah iOS meminta izin.
  • File dan video: SoundCatch hanya membaca file atau video yang Anda pilih (pemilih iOS, tanpa akses ke seluruh perpustakaan foto). File hasil ekspor disimpan di tempat yang Anda tentukan (File atau lembar berbagi); aplikasi tidak menyimpan salinannya.
  • Tidak ada data yang dikumpulkan, tanpa akun, tanpa iklan, tanpa koneksi ke server mana pun.

Di Android

  • Suara aplikasi lain: saat Anda memulai perekaman, Android meminta persetujuan Anda untuk merekam; untuk itu Android mewajibkan izin “Mikrofon”, tetapi SoundCatch hanya merekam suara yang diputar oleh aplikasi (musik, video, game), tidak pernah mikrofon. Sebuah notifikasi tetap tampil di layar selama perekaman berlangsung.
  • File: SoundCatch hanya membaca file yang Anda pilih dengan pemilih Android dan menulis file hasil ekspor di tempat yang Anda pilih. Rekaman dan salinan kerja tetap berada di ruang pribadi aplikasi di ponsel Anda.
  • Tidak ada data yang dikumpulkan, tanpa akun, tanpa iklan, tanpa koneksi ke server mana pun.

Apa yang tidak dikirim aplikasi

Tidak ada. Aplikasi ini tidak berisi alat analitik, iklan, atau pelaporan error, dan tidak bertukar data apa pun dengan penerbit maupun dengan pihak ketiga mana pun.

Tautan “Laporkan masalah”

Tautan ini membuka aplikasi email Anda dengan pesan yang ditujukan kepada penerbit. Tidak ada yang dikirim sampai Anda sendiri mengirimkannya; penerbit kemudian hanya menerima apa yang Anda tulis dan alamat email Anda, dan hanya menggunakannya untuk membalas Anda.

Hak atas karya

Rekam suara untuk penggunaan pribadi Anda dan hormati hak atas karya serta ketentuan layanan yang Anda dengarkan.
