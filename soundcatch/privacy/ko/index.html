개인정보 처리방침 — SoundCatch

최종 업데이트: 2026년 10월 23일

SoundCatch(Mac에서의 이전 이름: “MP3 Universal Converter”)는 Mac, Windows, iPhone 및 Android용 오디오 레코더입니다. 앱의 소리를 녹음하거나 오디오 또는 비디오 파일을 열고, 그 일부를 잘라 낸 다음, 사용자가 정한 위치에 파일을 내보낼 수 있습니다. 이 페이지에서는 각 버전에 대해 설명합니다.

요약: 수집하는 데이터 없음, 계정 없음, 광고 없음, 이용자 분석 도구 없음. 앱은 어떤 서버에도 연결하지 않습니다. 사용자가 녹음한 소리, 연 파일, 내보낸 파일은 사용자의 기기에 남습니다.

SoundCatch는 프랑스에 기반을 둔 개인 개발자 Atria.Eponym이 배포합니다. 연락처: atria.eponym@gmail.com

Mac용

  • 오디오 녹음: macOS가 “오디오 녹음” 권한을 한 번 요청합니다. 앱은 사용자가 선택한 앱의 소리만, 그리고 녹음 버튼을 클릭한 순간부터 녹음을 멈춘 순간까지만 캡처합니다. 앱은 마이크를 사용하지 않습니다.
  • 파일: 앱은 사용자가 창에서 열거나 창에 끌어다 놓은 파일만 읽고, 사용자가 선택한 폴더에 내보낸 파일만 씁니다. 작업용 사본은 macOS의 임시 폴더에 보관되며 앱을 닫을 때 삭제됩니다.
  • 앱 목록: 소리를 재생하는 앱을 보여 주기 위해, 앱은 macOS가 관리하는 실행 중인 오디오 앱 목록을 확인합니다. 이 목록은 저장되지도 전송되지도 않습니다.
  • 환경설정: 마지막으로 사용한 포맷과 소스, 청취 음량, 내보내기 폴더는 사용자의 Mac에 있는 앱의 환경설정에 저장됩니다. Mac App Store 버전은 여기에 성공한 내보내기 횟수와 마지막 평가 요청 날짜를 추가로 저장합니다.
  • 평가 요청(Mac App Store 버전): 두 번째 내보내기에 성공한 후, 최대 120일에 한 번, 앱은 macOS에 App Store의 공식 평가 창을 표시하도록 요청합니다. 이 창은 Apple이 관리하며, 앱은 사용자가 평가를 남겼는지 알지 못합니다.

Windows용

  • 앱의 소리: SoundCatch는 사용자가 선택한 앱의 소리(또는 사용자가 선택한 경우 PC의 모든 소리)만, 그리고 녹음 버튼을 클릭한 순간부터 녹음을 멈춘 순간까지만 캡처합니다. 앱은 마이크를 사용하지 않습니다.
  • 파일: 앱은 사용자가 창에서 열거나 창에 끌어다 놓은 파일만 읽고, 사용자가 선택한 폴더에 내보낸 파일만 씁니다. 작업용 사본은 Windows의 임시 폴더에 보관되며 앱을 닫을 때 삭제됩니다.
  • 환경설정 및 평가 요청: Mac과 마찬가지로 환경설정은 사용자의 PC에 남습니다. Microsoft Store 버전은 두 번째 내보내기에 성공한 후, 최대 120일에 한 번, Windows에 공식 평가 창을 표시하도록 요청합니다.
  • 수집하는 데이터 없음, 계정 없음, 광고 없음, 서버 연결 없음.

iPhone용

  • 다른 앱의 소리: 사용자가 SoundCatch에서 방송을 시작하면, iOS는 앱에서 재생되는 소리를 SoundCatch의 확장 프로그램에 전달합니다. 확장 프로그램은 그 소리만 보관하며, 화면 영상과 마이크는 도착하는 즉시 폐기됩니다. 소리는 사용자가 삭제할 때까지 iPhone의 SoundCatch 공간에 저장됩니다.
  • 마이크: 사용자가 « Enregistrer avec le micro » 버튼을 탭할 때만, iOS의 권한 요청을 거친 후 사용됩니다.
  • 파일 및 비디오: SoundCatch는 사용자가 선택한 파일이나 비디오만 읽습니다(iOS 선택기를 사용하며, 사진 보관함 전체에는 접근하지 않습니다). 내보낸 파일은 사용자가 정한 위치(파일 또는 공유)로 이동하며, 앱은 사본을 보관하지 않습니다.
  • 수집하는 데이터 없음, 계정 없음, 광고 없음, 서버 연결 없음.

Android용

  • 다른 앱의 소리: 사용자가 녹음을 시작하면 Android가 캡처 동의를 요청합니다. 이를 위해 Android는 “마이크” 권한을 요구하지만, SoundCatch는 앱에서 재생되는 소리(음악, 동영상, 게임)만 녹음하며 마이크는 절대 녹음하지 않습니다. 녹음하는 동안에는 알림이 계속 표시됩니다.
  • 파일: SoundCatch는 사용자가 Android 선택기로 고른 파일만 읽고, 내보낸 파일은 사용자가 선택한 위치에 씁니다. 녹음과 작업용 사본은 휴대전화의 앱 전용 공간에 남습니다.
  • 수집하는 데이터 없음, 계정 없음, 광고 없음, 서버 연결 없음.

앱이 전송하지 않는 것

아무것도 전송하지 않습니다. 앱에는 통계, 광고 또는 충돌 보고 도구가 전혀 포함되어 있지 않으며, 배포자나 제3자와 어떤 데이터도 주고받지 않습니다.
