Политика конфиденциальности — SoundCatch

Последнее обновление: 23 октября 2026 г.

SoundCatch (ранее «MP3 Universal Converter» на Mac) — аудиорекордер для Mac, Windows, iPhone и Android. Он записывает звук приложения или открывает аудио- или видеофайл, позволяет вырезать из него фрагменты, а затем экспортирует файл туда, куда вы решите. На этой странице описана каждая версия.

Главное: никакие данные не собираются, нет учётной записи, нет рекламы, нет инструментов измерения аудитории. Приложение не подключается ни к какому серверу: звук, который вы записываете, файлы, которые вы открываете, и файлы, которые вы экспортируете, остаются на вашем устройстве.

На Mac

  • Запись аудио: macOS один раз запрашивает у вас разрешение «Запись аудио». Приложение захватывает только звук выбранного вами приложения и только с момента, когда вы нажимаете кнопку записи, до момента, когда вы её останавливаете. Оно не использует микрофон.
  • Файлы: оно читает только файлы, которые вы открываете или перетаскиваете в его окно, и записывает только экспортированный файл — в выбранную вами папку. Рабочие копии хранятся во временной папке macOS и удаляются при закрытии приложения.
  • Список приложений: чтобы предложить вам приложения, воспроизводящие звук, оно обращается к списку открытых аудиоприложений, который ведёт macOS. Этот список не сохраняется и не передаётся.
  • Настройки: последний формат, последний источник, громкость прослушивания и папка экспорта запоминаются на вашем Mac, в настройках приложения. Версия из Mac App Store дополнительно хранит там число успешных экспортов и дату последнего запроса отзыва.
  • Запрос отзыва (версия из Mac App Store): после второго успешного экспорта, не чаще одного раза в 120 дней, приложение просит macOS показать официальное окно отзыва App Store. Этим окном управляет Apple; приложение не знает, поставили ли вы оценку.

На Windows

  • Звук приложения: SoundCatch захватывает только звук выбранного вами приложения (или весь звук ПК, если вы выберете этот вариант) и только с момента, когда вы нажимаете кнопку записи, до момента, когда вы её останавливаете. Оно не использует микрофон.
  • Файлы: оно читает только файлы, которые вы открываете или перетаскиваете в его окно, и записывает только экспортированный файл — в выбранную вами папку. Рабочие копии хранятся во временной папке Windows и удаляются при закрытии приложения.
  • Настройки и запрос отзыва: как и на Mac, настройки остаются на вашем ПК; версия из Microsoft Store просит Windows показать официальное окно отзыва после второго успешного экспорта, не чаще одного раза в 120 дней.
  • Никакие данные не собираются, нет учётной записи, нет рекламы, нет подключения к серверу.

На iPhone

  • Звук другого приложения: когда вы запускаете трансляцию из SoundCatch, iOS передаёт расширению SoundCatch звук, воспроизводимый приложениями. Оно сохраняет только этот звук; изображение экрана и микрофон отбрасываются сразу при поступлении. Звук хранится в пространстве SoundCatch на вашем iPhone, пока вы его не удалите.
  • Микрофон: используется только тогда, когда вы нажимаете « Enregistrer avec le micro », после разрешения, запрошенного iOS.
  • Файлы и видео: SoundCatch читает только файл или видео, которые вы выбираете (средства выбора iOS, без доступа ко всей медиатеке). Экспортированный файл сохраняется туда, куда вы решите (Файлы или «Поделиться»); приложение не хранит его копию.
  • Никакие данные не собираются, нет учётной записи, нет рекламы, нет подключения к серверу.

На Android

  • Звук других приложений: когда вы запускаете запись, Android запрашивает у вас разрешение на захват; для этого он требует разрешение «Микрофон», но SoundCatch записывает только звук, воспроизводимый приложениями (музыка, видео, игры), и никогда — микрофон. Пока идёт запись, на экране остаётся уведомление.
  • Файлы: SoundCatch читает только файл, который вы выбираете с помощью средства выбора Android, и записывает экспортированный файл туда, куда вы укажете. Записи и рабочие копии остаются в личном пространстве приложения на вашем телефоне.
  • Никакие данные не собираются, нет учётной записи, нет рекламы, нет подключения к серверу.

Что приложение не отправляет

Ничего. В нём нет никаких инструментов статистики, рекламы или отчётов о сбоях, и оно не обменивается никакими данными ни с издателем, ни с третьими лицами.
