SoundCatch내부 소리 녹음기 겸 오디오 편집기

녹음 · 자르기 · 내보내기

SoundCatch는 Windows PC와 Android용 무료 내부 소리 녹음기입니다. 앱에서 나오는 소리, 또는 PC나 휴대폰의 모든 소리를 마이크를 거치지 않고 녹음합니다. 오디오 파일이나 동영상을 열어 소리를 추출할 수도 있습니다. 그다음 오디오 편집기처럼 들어 보고, 필요 없는 부분을 잘라 내고, 깔끔한 파일로 내보내면 됩니다. 광고도 계정도 없습니다.

앱 소리 녹음하기, PC와 Android에서

소리를 녹음할 앱 또는 기기의 모든 소리를 고르고 녹음을 시작한 다음, 음악이나 동영상을 재생하세요. SoundCatch는 앱이 재생하는 소리만 녹음합니다. 마이크는 절대 사용하지 않으므로 목소리나 방 안의 소음은 들어가지 않습니다. 소리는 스튜디오 품질로 보관되고 내보낼 때 한 번만 인코딩됩니다.

Windows PC에서

  • Windows 11에서는 앱 하나의 소리(브라우저, 플레이어, 음악 프로그램, 게임) 또는 PC의 모든 소리를, Windows 10에서는 PC의 모든 소리를 녹음합니다.
  • 가상 드라이버나 케이블을 설치할 필요가 없습니다.
  • PC 볼륨을 바꿔도 녹음 레벨은 바뀌지 않습니다.

Android에서

  • 앱의 소리 또는 휴대폰의 모든 소리를 원래 샘플링 레이트(보통 48 kHz) 그대로 32비트 부동소수점으로 녹음합니다.
  • 3초가 지나도 소리가 들어오지 않으면 앱이 알려 주고 이유를 설명합니다.

Android는 녹음할 때마다 동의를 요청합니다. 화면을 켜 두세요. 휴대폰이 잠기면 Android가 녹음을 멈춥니다. 일부 앱은 소리 녹음을 금지하며, 이 경우 Android는 무음만 전달합니다.

이음매에서 딸깍 소리 없이 오디오 파일 자르기

편집은 파형 위에서 PC는 마우스로, Android는 손가락으로 합니다. 구간을 선택하고, 들어 보고, 삭제하세요.

  • 여러 구간을 한 번에.
  • 이음매마다 20 ms 크로스페이드: 자른 자리가 들리지 않습니다.
  • 전체 기록: 실행 취소, 다시 실행, 원하는 단계로 돌아가기.
  • 의심스러운 구간을 알려 드립니다: 음악 중간의 말소리, 공백, 갑작스러운 음량이나 음색 변화. 직접 들어 보고 결정하세요. 확인 없이 잘리는 것은 없습니다.
  • 처음과 끝의 무음은 내보낼 때 제거할 수 있습니다.

동영상에서 소리 추출하기

어떤 오디오 파일이나 동영상 파일이든 열면 SoundCatch가 그 소리를 가져옵니다. 그런 다음 녹음처럼 잘라서 내보내면 됩니다. 개인 사진·동영상 편집의 배경음악을 준비할 때 유용합니다.

MP3, AAC, FLAC로 내보내기

  • Windows PC: AAC(.m4a), MP3 320 kbit/s, Apple Lossless 또는 FLAC.
  • Android: 거의 어디서나 재생되는 AAC(.m4a) 256 kbit/s 또는 무손실 FLAC. 시스템에 MP3 인코더가 없어 MP3는 제공되지 않습니다.
  • 내보내기 전에 형식별 파일 크기가 표시됩니다.
  • 파일을 저장할 위치를 직접 고를 수 있습니다.

Windows, Android, Mac, iPhone: 버전별 기능

핵심은 어디서나 같습니다. 녹음하고, 딸깍 소리 없이 자르고, 의심스러운 구간을 찾아내고, 깔끔한 파일로 내보냅니다. 각 버전은 해당 시스템이 허용하는 범위를 따릅니다.

Windows PC · 출시됨

  • 앱의 소리(Windows 11) 또는 PC의 모든 소리, 마이크는 사용하지 않음.
  • 마우스로 편집.
  • AAC(.m4a), MP3 320 kbit/s, Apple Lossless 또는 FLAC로 내보내기.
  • Windows 10(버전 1809 이상) 또는 Windows 11.

Android · 출시됨

  • 앱의 소리 또는 휴대폰의 모든 소리, 마이크는 사용하지 않음.
  • 휴대폰의 오디오 및 동영상 파일.
  • AAC(.m4a) 또는 FLAC로 내보내기.
  • Android 10 이상.

Mac · 준비 중

  • 목록에서 고른 앱의 소리 또는 Mac의 모든 소리, 오디오 드라이버 설치 필요 없음, 마이크는 사용하지 않음.
  • AAC(.m4a), MP3 320 kbit/s, Apple Lossless 또는 FLAC로 내보내기.
  • Apple 실리콘 Mac, macOS 14.4 이상.

iPhone · 준비 중

  • iOS 방송 기능을 통한 다른 앱의 소리, 주변에서 재생되는 소리를 위한 마이크, 사진 앱의 동영상.
  • AAC(.m4a), Apple Lossless 또는 FLAC로 내보내기.
  • iOS 17 이상.

녹음은 기기에만 남습니다

  • 계정도 가입도 없습니다.
  • 광고도, 이용자 분석 도구도, 데이터 수집도 없습니다.
  • 녹음한 소리와 내보낸 파일은 개발자의 어떤 서버로도 전송되지 않습니다.

자주 묻는 질문

SoundCatch는 무료인가요?

네. SoundCatch는 무료이며 광고도 없고 계정을 만들 필요도 없습니다. Windows PC와 Android 모두 마찬가지입니다.

PC에서 나오는 소리는 어떻게 녹음하나요?

SoundCatch에서 소리를 녹음할 앱 또는 PC의 모든 소리를 고르고 둥근 버튼을 클릭한 다음 음악을 재생하세요. 앱 하나만 녹음하려면 Windows 11이 필요하며, Windows 10에서는 SoundCatch가 PC의 모든 소리를 녹음합니다. 가상 드라이버나 케이블은 필요 없습니다.

Android 휴대폰의 내부 소리는 어떻게 녹음하나요?

소리를 녹음할 앱 또는 휴대폰의 모든 소리를 고르고, 둥근 버튼을 누른 뒤 Android의 요청을 수락하세요. 그런 다음 해당 앱에서 음악을 재생하고 SoundCatch로 돌아와 녹음을 멈추면 됩니다. Android 10 이상이 필요합니다. 일부 앱은 소리 녹음을 금지하며, 이 경우 Android는 무음만 전달하고 SoundCatch가 이를 알려 드립니다.

SoundCatch는 마이크 소리도 녹음하나요?

아니요, PC에서도 Android에서도 녹음하지 않습니다. 앱이 재생하는 소리만 녹음되며 목소리나 방 안의 소음은 들어가지 않습니다. 준비 중인 iPhone 버전은 마이크도 지원할 예정입니다.

MP3로 내보낼 수 있나요?

Windows PC에서는 AAC, Apple Lossless, FLAC와 함께 MP3 320 kbit/s로 내보낼 수 있습니다. Android에는 MP3 인코더가 없어 지원되지 않으며, 거의 어디서나 재생되는 AAC(.m4a) 또는 FLAC로 내보냅니다.

동영상에서 소리를 추출할 수 있나요?

네. SoundCatch에서 동영상을 열면 그 소리가 보존됩니다. 그런 다음 잘라서 내보낼 수 있습니다.

녹음이 어딘가로 전송되나요?

아니요. 소리와 내보낸 파일은 기기에 남습니다. SoundCatch에는 계정도, 광고도, 이용자 분석 도구도 없습니다.
