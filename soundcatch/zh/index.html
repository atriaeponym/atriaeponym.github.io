SoundCatch内录软件与音频编辑器

录制 · 剪辑 · 导出

SoundCatch 是一款适用于 Windows 电脑和 Android 的免费内录软件。它可以录制某个应用发出的声音，或电脑、手机的全部声音，完全不经过麦克风。它也能打开音频文件或视频，提取其中的声音。之后就像使用音频编辑器一样：试听、剪掉多余片段，再导出一个干净的文件。无广告，无需账号。

录制应用的声音，电脑和 Android 均可

选择要录制声音的应用，或设备的全部声音，开始录制，然后播放您的音乐或视频。SoundCatch 只录制应用播放的声音：绝不使用麦克风，因此不会录进您的说话声或房间里的噪音。声音以录音室品质保存，仅在导出时编码一次。

在 Windows 电脑上

  • 在 Windows 11 上可录制单个应用的声音（浏览器、播放器、音乐软件、游戏）或电脑的全部声音；在 Windows 10 上录制电脑的全部声音。
  • 无需安装虚拟驱动或连接线。
  • 电脑音量不会改变录制电平。

在 Android 上

  • 应用的声音，或手机的全部声音，以原始采样率（通常为 48 kHz）、32 位浮点录制。
  • 如果 3 秒后仍没有声音，应用会提示您并说明原因。

每次录制时 Android 都会请求您的同意。请保持屏幕常亮：手机锁屏后 Android 会停止录制。部分应用禁止录制其声音；此时 Android 只会传来静音。

剪辑音频文件，衔接处没有咔嗒声

在波形上剪辑：电脑上用鼠标，Android 上用手指。选择一个片段，试听，删除。

  • 可同时选择多个片段。
  • 每个衔接处 20 ms 淡入淡出：听不出剪切的痕迹。
  • 完整的历史记录：撤销、重做，或回到任意一步。
  • 可疑片段会提示给您：音乐中间的说话声、空白、音量或音色的突然变化。由您试听并决定：未经您同意，不会剪掉任何内容。
  • 开头和结尾的静音可在导出时去除。

从视频中提取声音

打开任意音频或视频文件：SoundCatch 会保留其中的声音。然后像处理录音一样剪辑并导出。适合为个人照片或视频剪辑准备配乐。

导出为 MP3、AAC 或 FLAC

  • Windows 电脑：AAC（.m4a）、MP3 320 kbit/s、Apple Lossless 或 FLAC。
  • Android：AAC（.m4a）256 kbit/s，几乎随处可播放，或无损 FLAC。不提供 MP3：系统没有 MP3 编码器。
  • 导出前会显示每种格式的文件大小。
  • 由您选择文件的保存位置。

常见问题

SoundCatch 免费吗？

是的。SoundCatch 免费，无广告，无需创建账号，Windows 电脑和 Android 上都是如此。

如何录制电脑发出的声音？

在 SoundCatch 中选择要录制声音的应用，或电脑的全部声音，点击圆形按钮，然后播放您的音乐。仅录制单个应用需要 Windows 11；在 Windows 10 上，SoundCatch 录制电脑的全部声音。无需虚拟驱动或连接线。

如何录制 Android 手机的内部声音？

选择要录制声音的应用，或手机的全部声音，轻点圆形按钮并接受 Android 的请求。然后在该应用中播放您的音乐，回到 SoundCatch 停止录制。需要 Android 10 或更高版本。部分应用禁止录制其声音：此时 Android 只会传来静音，SoundCatch 会提示您。

SoundCatch 会录制麦克风吗？

不会，电脑和 Android 上都不会：只录制应用播放的声音，不会录进您的说话声或房间里的噪音。准备中的 iPhone 版还将支持麦克风。

可以导出为 MP3 吗？

在 Windows 电脑上可以，MP3 320 kbit/s，此外还有 AAC、Apple Lossless 和 FLAC。Android 上不行，因为它没有 MP3 编码器：应用在 Android 上导出为几乎随处可播放的 AAC（.m4a）或 FLAC。

可以从视频中提取声音吗？

可以。在 SoundCatch 中打开视频：其中的声音会被保留。然后您可以剪辑并导出。

我的录音会被发送到别处吗？

不会。声音和导出的文件都保存在您的设备上。SoundCatch 没有账号、没有广告，也没有受众统计工具。
